# AgentMemory

把本机各个 AI 编码工具的对话记录（Claude Code、Codex CLI、Continue 等）自动整理成 Markdown，
落到你指定的归档目录，并可选地推送到你自己的 git 仓库。

## 网页版捕获插件

`extension/` 是桌面版的配套 Chrome / Edge 插件，不是另一套独立产品：它把网页版 AI 对话批量保存成 Markdown，写到桌面归档目录的 `网页版/<站点>/`，桌面端按「桌面端 / 网页版」分开统计；也可以在插件里单独选一个保存目录。

目前支持：

- DeepSeek、Kimi、腾讯元宝：批量保存、增量跳过、标题变化只保留一份文件。
- ChatGPT：入口保留，真实站点尚未校准。

桌面端的本机渠道以应用「渠道」页为准；插件的安装、取数方式和真实站点验证清单见 `extension/README.md`。Release 同时提供桌面版 `AgentMemory.exe` 和插件 `AgentMemory-Web-<版本>.zip`。

桌面版分发说明见 [PORTABLE-README.md](PORTABLE-README.md)。

## 收集是怎么工作的：增量收集

首页那个按钮叫「**增量收集**」，意思是**只收新出现的**：

- **第一次**点：机器上现有的会话**全收**一遍（该有多少就有多少）
- **之后每次**点：只收**新出现**的会话——已经收过的不会重复写一遍
- 判断依据是每个源文件的落盘时间与归档目录里的存档（游标记着处理过哪些）

所以你可以随时点它：第一遍慢（有多少收多少），后面都是几十毫秒的事。
定时任务跑的是同一件事，只是由系统的计划任务在每天那个点替你点一下。

想改归档目录、备份方式、定时时间，点右上角导航栏的「设置」。

**换归档目录**：旧目录里的归档不会自己跟过来。设置页里那个「复制旧目录里的 N 段归档过来」
可以把它们**复制**到新目录——只复制，旧目录里的不动；撞上同名但内容不同的会停下来告诉你，
不会覆盖也不会删。搬完首页「已收集 / 待收集」当场重算。

**用 Git 仓库备份**：不用手填地址。设置页里那一块是三步：
① 建仓库（本机建一个，网页建一个空仓库）② 把那段话复制给你的 AI——它会一步一步带你建仓库、
配密钥、配远程 ③ 回到这里点「试连」。程序会自己从本地仓库里认出远程地址，认到就记进配置。

## 升级与卸载：数据不跟着程序走

程序和你的数据是分开放的。升级只换程序文件，卸载也不碰数据。

- **升级**：先退出程序，用新版本的程序文件覆盖旧的（放回同一个目录即可），再打开。
  设置、归档、游标、运行记录都还在原来的地方，不会丢，也不用重走首次引导。
- **旧版本的配置**：打开时按版本自动迁移，迁移只做加法（补字段），不丢已有的设置。
- **卸载**：删掉程序文件或程序目录就行。下面两处数据要删的话得你自己动手，程序不会顺手删。
- **数据在哪**：
  - 配置、游标、运行记录：`%APPDATA%\AgentMemory`（可以用环境变量 `AGENTMEMORY_HOME` 换地方）
  - 归档：设置页里选的那个归档目录（默认 `%USERPROFILE%\Documents\AgentMemory`）
- **升级前想留个底**：备份上面这两个目录就够了。

## 开发：跑测试

```bash
export GOTMPDIR="$PWD/.gotmp"   # Go 的临时编译目录挪到项目里（默认在系统临时目录）
go test ./...
```

为什么挪：`go test` 会把每个包的测试编译成临时二进制（`<包名>.test.exe`），
放在系统临时目录里。**杀软的行为检测常把这些「新编译、没签名、会拉起进程」的文件报成风险软件**
（甚至中途拦掉，测试就会莫名其妙失败）。挪到项目里之后，给项目目录加一次排除项就都盖住了。
